Prerequisites

Open OpenSearch Dashboards at http://<server-ip>:5601 and log in with your credentials (default: admin / admin).

Step 0: Create Index Pattern

  1. Go to Stack Management → Index Patterns
  2. Click Create index pattern
  3. Enter: supra-logs-*
  4. Select @timestamp as the time field
  5. Click Create index pattern

Step 1: Verify Fields Are Available

  1. Go to Discover
  2. Select supra-logs-* index pattern
  3. Test each source type in the search bar:
Query Expected Result
source_type: "ied" IED Hitachi Energy REC670/REL670 logs
source_type: "network" Network Switches, routers, firewall logs
source_type: "windows" Windows Workstation/server event logs
Available Fields: Check the left panel in Discover for fields like event_type, severity, ied_model, device_id, user, event_code, host, etc.

IED Dashboard 1: IED Monitoring (REC670 / REL670)

Base Filter for all IED visualizations: source_type → is → ied

Create Saved Search (Base Filter)

  1. Go to Discover
  2. Add filter: source_type → is → ied
  3. Click Save → name it IED Logs - Base

Visualization 1.1: IED Event Count Over Time (Line Chart)

  1. Go to Visualize → Create visualization → Line
  2. Select supra-logs-*
  3. Metrics: Y-axis → Aggregation: Count
  4. Buckets:
    • X-axis → Aggregation: Date Histogram, Field: @timestamp, Interval: Auto
    • Add sub-bucket → Split series → Aggregation: Terms, Field: event_type.keyword, Size: 10
  5. Add filter: source_type → is → ied
  6. Click Update → Save as IED - Event Count Over Time

Visualization 1.2: Severity Distribution (Pie Chart)

  1. Visualize → Create visualization → Pie
  2. Select supra-logs-*
  3. Metrics: Slice size → Count
  4. Buckets: Split slices → Terms, Field: severity.keyword, Size: 5
  5. Filter: source_type → is → ied
  6. Save as IED - Severity Distribution

Visualization 1.3: Event Type Breakdown (Horizontal Bar)

  1. Visualize → Create → Horizontal Bar
  2. Metrics: Y-axis → Count
  3. Buckets: X-axis → Terms, Field: event_type.keyword, Size: 10
  4. Filter: source_type → is → ied
  5. Save as IED - Event Type Breakdown

Visualization 1.4: Events Per Device (Data Table)

  1. Visualize → Create → Data Table
  2. Metrics: Count
  3. Buckets:
    • Split rows → Terms, Field: device_id.keyword, Size: 20, Label: Device ID
    • Add sub-bucket → Split rows → Terms, Field: ied_model.keyword, Size: 5, Label: IED Model
    • Add sub-bucket → Split rows → Terms, Field: event_type.keyword, Size: 10, Label: Event Type
  4. Filter: source_type → is → ied
  5. Save as IED - Events Per Device

Visualization 1.5: User Activity (Vertical Bar)

  1. Visualize → Create → Vertical Bar
  2. Metrics: Y-axis → Count
  3. Buckets:
    • X-axis → Terms, Field: user.keyword, Size: 10
    • Split series → Terms, Field: event_type.keyword, Size: 10
  4. Filter: source_type → is → ied
  5. Save as IED - User Activity

Visualization 1.6: Critical & Warning Alerts (Metric)

  1. Visualize → Create → Metric
  2. Metrics: Count
  3. Filter: source_type → is → ied AND severity → is one of → critical, warning
  4. Save as IED - Critical & Warning Count

Visualization 1.7: Login/Logout Timeline (Area Chart)

  1. Visualize → Create → Area
  2. Metrics: Y-axis → Count
  3. Buckets:
    • X-axis → Date Histogram, Field: @timestamp, Interval: Auto
    • Split series → Terms, Field: event_type.keyword, Size: 5
  4. Filter: source_type → is → ied AND event_type → is one of → login, logout
  5. Save as IED - Login/Logout Timeline

Visualization 1.8: Recent IED Events (Saved Search)

  1. Go to Discover
  2. Filter: source_type → is → ied
  3. Select columns from left panel (click +): @timestamp, host, device_id, ied_model, event_type, severity, event_description, user
  4. Sort by @timestamp descending
  5. Save as IED - Recent Events Log

Assemble IED Dashboard

  1. Go to Dashboards → Create new
  2. Click Add and add all saved visualizations listed below
  3. Save dashboard as Supra IED Monitoring - REC670

Recommended Layout

IED - Critical & Warning Count
IED - Severity Distribution
IED - Event Type Breakdown
IED - Event Count Over Time
IED - Events Per Device
IED - User Activity
IED - Login/Logout Timeline
IED - Recent Events Log

Windows Dashboard 3: Windows Workstations / Servers

Note: Windows fields depend on NXLog JSON output. Common fields: Hostname, SourceName, EventID, EventType, Channel, Message, AccountName, Category.

Visualization 3.1: Windows Events Over Time (Line Chart)

  1. Visualize → Create → Line
  2. Select supra-logs-*
  3. Metrics: Y-axis → Count
  4. Buckets:
    • X-axis → Date Histogram, Field: @timestamp, Interval: Auto
    • Split series → Terms, Field: Channel.keyword, Size: 10
  5. Filter: source_type → is → windows
  6. Save as Windows - Events Over Time

Visualization 3.2: Events by Source (Vertical Bar)

  1. Visualize → Create → Vertical Bar
  2. Metrics: Y-axis → Count
  3. Buckets:
    • X-axis → Terms, Field: SourceName.keyword, Size: 15
    • Split series → Terms, Field: EventType.keyword, Size: 5
  4. Filter: source_type → is → windows
  5. Save as Windows - Events by Source

Visualization 3.3: Event Type Distribution (Pie Chart)

  1. Visualize → Create → Pie
  2. Metrics: Slice size → Count
  3. Buckets: Split slices → Terms, Field: EventType.keyword, Size: 10
  4. Filter: source_type → is → windows
  5. Save as Windows - Event Type Distribution

Visualization 3.4: Top Event IDs (Data Table)

  1. Visualize → Create → Data Table
  2. Metrics: Count
  3. Buckets:
    • Split rows → Terms, Field: EventID.keyword, Size: 20, Label: Event ID
    • Sub-bucket → Terms, Field: SourceName.keyword, Size: 3, Label: Source
    • Sub-bucket → Terms, Field: Hostname.keyword, Size: 5, Label: Host
  4. Filter: source_type → is → windows
  5. Save as Windows - Top Event IDs

Visualization 3.5: Events Per Workstation (Horizontal Bar)

  1. Visualize → Create → Horizontal Bar
  2. Metrics: Y-axis → Count
  3. Buckets: X-axis → Terms, Field: Hostname.keyword, Size: 20
  4. Filter: source_type → is → windows
  5. Save as Windows - Events Per Workstation

Visualization 3.6: Security Events - Login Failures (Metric)

  1. Visualize → Create → Metric
  2. Metrics: Count
  3. Filter: source_type → is → windows AND EventID → is one of → 4625, 4771
  4. Save as Windows - Failed Login Count
Tip: Windows Event ID 4625 = Failed logon attempt, 4771 = Kerberos pre-authentication failed. These are key security indicators.

Visualization 3.7: Security Events Over Time (Area Chart)

  1. Visualize → Create → Area
  2. Metrics: Y-axis → Count
  3. Buckets:
    • X-axis → Date Histogram, Field: @timestamp, Interval: Auto
    • Split series → Terms, Field: EventID.keyword, Size: 10
  4. Filter: source_type → is → windows AND Channel → is → Security
  5. Save as Windows - Security Events Timeline

Visualization 3.8: Recent Windows Events (Saved Search)

  1. Discover → Filter: source_type → is → windows
  2. Select columns: @timestamp, Hostname, Channel, EventID, SourceName, EventType, Message
  3. Sort by @timestamp descending
  4. Save as Windows - Recent Events Log

Assemble Windows Dashboard

  1. Go to Dashboards → Create new
  2. Click Add and add all Windows visualizations
  3. Save dashboard as Supra Windows Monitoring

Recommended Layout

Windows - Failed Login Count
Windows - Event Type Distribution
Windows - Events Per Workstation
Windows - Events Over Time
Windows - Events by Source
Windows - Top Event IDs
Windows - Security Events Timeline
Windows - Recent Events Log

Summary

Dashboard Filter Key Panels
Supra IED Monitoring - REC670 source_type: ied Event timeline, severity pie, device table, user activity, login/logout, critical alerts
Supra Network Monitoring source_type: network Link up/down, events per device IP, critical count, syslog source table
Supra Windows Monitoring source_type: windows Events by source/channel, failed logins, security timeline, event ID table
Tip: All three dashboards use the same index pattern (supra-logs-*) but are filtered by source_type. Use the time picker at the top of each dashboard to narrow down to specific time ranges.

Port Reference

Port Protocol Source Format
514 UDP + TCP IEDs (REC670, REL670) Syslog (UTC)
1514 UDP Windows NXLog agents JSON (IST)
2514 UDP + TCP Switches, Routers, Firewalls Syslog (IST)
24224 TCP Fluentd agents Forward protocol
